# Instruções para o Claude

## Sempre perguntar o projeto

Toda vez que o usuário pedir um **trabalho novo** (código, documento, design,
análise, artefato etc.), antes de começar pergunte em qual projeto esse
trabalho deve ser colocado. Use as opções de `config/projetos.md`.
Não pergunte se o projeto já foi informado na mensagem ou nesta conversa,
nem para perguntas rápidas ou continuações do mesmo trabalho.
